# Diplom_2
Файл urls.py содержит ссылки для api

Папка api_methods:

- orders_api.py описывает методы API для создания заказа
- user_api.py описывает методы API для создания, авторизации и удаления пользователя

Папка data:

- data.py содержит данные сообщений об ошибках
- order_data.py содержит данные для создания заказа

Папка helper:

- helpers.py содержит функцию создания уникальных данных для пользователя и функцию получения токена

Папка tests:

- conftest.py содержит в себе фикстуры на удаление, создание, авторизацию пользователя
- test_create_user содержит тесты на проверку создания пользователя
- test_login содержит тесты на авторизацию пользователя
- test_create_order содержит тесты на проверку создания заказа
