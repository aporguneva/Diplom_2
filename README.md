# Автотесты API Stellar Burgers

Проект автоматизированного тестирования API сервиса Stellar Burgers.

## О проекте

Разработан набор автотестов для проверки основных сценариев работы API Stellar Burgers: регистрации и авторизации пользователей, а также создания заказов.

Автотесты позволяют выполнять повторяемые регрессионные проверки API и получать подробный отчёт о результатах тестирования в Allure.

## Покрытые сценарии

### Создание пользователя

- создание уникального пользователя;
- попытка создания уже зарегистрированного пользователя;
- создание пользователя без обязательного поля `email`;
- создание пользователя без обязательного поля `password`;
- создание пользователя без обязательного поля `name`.

### Авторизация пользователя

- вход с корректными учётными данными;
- вход с некорректным логином и паролем.

### Создание заказа

- создание заказа с авторизацией;
- создание заказа без авторизации;
- создание заказа с ингредиентами;
- создание заказа без ингредиентов;
- создание заказа с неверным хешем ингредиента.

```text

├── data/

├── helper/
│   └── helpers.py
├── tests/
│   ├── conftest.py
│   ├── test_create_user.py
│   ├── test_login.py
│   └── test_create_order.py
├── urls.py
└── requirements.txt
```

### `urls.py`

Содержит URL и эндпоинты API, используемые в проекте.

### `api_methods/`

Содержит методы для взаимодействия с API:

- `orders_api.py` — методы API для создания заказа;
- `user_api.py` — методы API для создания, авторизации и удаления пользователя.

### `data/`

Содержит тестовые данные:

- `data.py` — ожидаемые сообщения об ошибках API;
- `order_data.py` — данные, используемые при создании заказов.

### `helper/`

Содержит вспомогательные функции:

- `helpers.py` — функции для генерации уникальных данных пользователя и получения токена авторизации.

### `tests/`

Содержит фикстуры и автотесты:

- `conftest.py` — фикстуры для создания, авторизации и удаления тестовых пользователей;
- `test_create_user.py` — тесты создания пользователя;
- `test_login.py` — тесты авторизации пользователя;
- `test_create_order.py` — тесты создания заказа.

## Что реализовано

- разработаны API-автотесты с использованием `pytest` и `requests`;
- покрыты позитивные и негативные сценарии для пользователей и заказов;
- применена параметризация `pytest` для однотипных проверок обязательных полей;
- реализована генерация уникальных тестовых данных с помощью `Faker`;
- реализована очистка тестовых данных после выполнения тестов;
- конфигурационные данные вынесены в переменные окружения;
- добавлены `title`, `description` и `step` для формирования читаемых Allure-отчётов;
- зафиксированы версии зависимостей проекта в `requirements.txt`;
- настроено формирование Allure-отчёта по результатам запуска тестов.

## Результат

Автоматизирована проверка основных API-сценариев Stellar Burgers, связанных с регистрацией, авторизацией пользователей и созданием заказов.

Набор тестов позволяет запускать регрессионную проверку одной командой и получать подробный Allure-отчёт с результатами каждого тестового сценария.

## Запуск проекта

Установить зависимости:

```bash id="yupmxr"
pip install -r requirements.txt
```

Запустить тесты:

```bash id="jjy0b4"
pytest
```

Запустить тесты с сохранением результатов для Allure:

```bash id="f1o8p6"
pytest --alluredir=allure_results
```

Сформировать Allure-отчёт:

```bash id="p6m0cu"
allure generate allure_results -o allure_report --clean
```

Открыть отчёт:

```bash id="ybg1ch"
allure open allure_report
```
